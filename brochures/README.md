# מחולל ידיעוני קורסים – היחידה ללימודי חוץ

תבנית אחידה להפקת ידיעונים (PDF בגודל A4) לכל הקורסים, בסגנון ידיעון CBT:
צבעי טורקיז כהה, ורוד ושמנת, גופן Heebo, כרטיסי מודולים, פס כהה וכריכה אחורית עם טלפון.

## מבנה

```
brochures/
  template/brochure.css    עיצוב (צבעים, טיפוגרפיה, רכיבים)
  template/brochure.js     בניית העמודים מתוך course.json
  render.mjs               הפקת HTML + PDF
  assets/                  לוגו וגופן
  courses/<קורס>/course.json   התוכן של הקורס
  courses/<קורס>/images/       תמונות הקורס
  output/                  הידיעונים המוכנים (PDF)
```

## הפקת ידיעון

```bash
cd brochures
node render.mjs courses/site-supervisor
# כמה קורסים בבת אחת:
node render.mjs courses/site-supervisor courses/<קורס-נוסף>
```

הסקריפט מתריע אם תוכן גולש מעמוד (`⚠ עמוד N: התוכן גולש`). במקרה כזה מקצרים טקסט, מקטינים `gap` של העמוד או מפצלים לשני עמודים.
עם `SCREENSHOTS=1` נשמרות גם תמונות תצוגה לכל עמוד ב-`output/preview/`.

## צבעים לכל קורס

ברירת המחדל היא צבעי ידיעון CBT. לקורס עם צבעים אחרים מוסיפים ל-`course.json` שדה `theme`, למשל (כחול-כתום של בקר אתר):

```json
"theme": { "primary": "#133a63", "primary-2": "#1e4d7f", "accent": "#ee7d22",
           "accent-light": "#f9a85a", "accent-soft": "#fde6cf", "paper": "#f3f4f6", "card": "#ffffff" }
```

`primary` – צבע ראשי (כותרות, פסים כהים) · `accent` – צבע הדגשה (מספרים, תוויות) · `accent-light` – הדגשה על רקע כהה · `paper` – רקע העמוד.
לכרטיסי נושא בשני טורים: `"columns": 2` בבלוק `topics`.

## קורס חדש

1. מעתיקים את `courses/site-supervisor` לתיקייה חדשה ומחליפים את התמונות.
2. עורכים את `course.json`: `cover` (כריכה), `back` (כריכה אחורית), ו-`pages` (רשימת עמודים).
3. כל עמוד הוא רשימת `blocks`. סוגי הבלוקים הזמינים:

| בלוק | שימוש |
|---|---|
| `heading` | תווית ורודה + כותרת + פסקת פתיחה |
| `lined` | כרטיסים עם קו עליון (אפשר `numbered`) |
| `darkBand` | פס כהה ברוחב מלא עם תרשים זרימה (`flow`) |
| `audienceTop` | עמוד "למי מתאים" עם תמונה בצד |
| `checks` | כרטיסי וי |
| `infoBox` | תיבה כהה (תנאי קבלה, הערות) |
| `curriculum` | טבלת תוכנית לימודים. עם `hours` מוצגים פסי שעות כמו ב-CBT |
| `iconCards` | כרטיסים עם אייקון (`style`: `plain` / `stack`) |
| `moduleHead` | ראש עמוד מודולים עם שבבי ניווט ותמונה |
| `module` | כרטיס מודול מלא: מה תלמדו, בסיום תוכלו, שיטות, הערכה, שעות |
| `topics` | כרטיסי נושא קומפקטיים (מספר, אייקון, כותרת, פסקה, `tag`) |
| `statement` | משפט גדול + שלוש שורות ("מזהים. עוצרים. מפנים.") |
| `bandNumber` | פס עם מספר גדול (למשל 50 שעות פרקטיקום) |
| `kv` | טבלת מפתח–ערך (הערכה, דוח לדוגמה) |
| `table` | טבלת נתונים, תאים יכולים להיות תגיות צבעוניות `{ "pill": "red", "text": "..." }` |
| `stats` | מספרים גדולים |
| `steps` | רצף שלבים ממוספר |
| `certificate` | בלוק התעודה/התוצרים בצבע מנטה עם תמונה |
| `image`, `banner` | תמונה / פס תמונה |
| `reading` | רשימת קריאה בשני טורים |
| `split` | שני טורים של בלוקים |
| `text`, `small`, `note`, `subheading`, `spacer` | טקסט |

בטקסט אפשר להשתמש ב-`**מודגש**` וב-`*נטוי*`. הוספת `"bottom": true` לבלוק מצמידה אותו לתחתית העמוד.
שמות האייקונים מופיעים ב-`ICONS` בקובץ `template/brochure.js`.
